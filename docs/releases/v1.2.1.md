# Squarebox v1.2.1 migration guide

v1.2 is a compatible upgrade from v1.1. It adds optional tools, refreshes
selected image-tier tools, and improves the managed Zellij defaults without
changing the `FORMAT=1` Install identity or its adapter boundary.

The protected v1.2.0 Candidate was not published after final qualification
found that Dev Container rebuilds discarded Managed-home state. v1.2.1 is the
first stable v1.2 release and includes the rebuild-stable Managed-home mount.

## Before upgrading

1. Commit or back up Workspace changes.
2. Record the installed source SHA and image digest from
   `<SQUAREBOX_DIR>/.squarebox/install-state`.
3. Keep the Managed home unless you intentionally want to reset authentication,
   histories, assistants, and mise toolchains.
4. Continue using the lifecycle adapter that created the Install identity.
   Native PowerShell and Git Bash state remains deliberately split by
   adapter.

Pre-v1.1 installations still need the explicit adoption procedure documented in
the [v1.1 migration guide](v1.1.0.md). v1.2 does not remove that compatibility
boundary.

## Upgrade

After v1.2.1 is published, run `sqrbx-rebuild` from an existing v1.1
installation. The rebuild resolves the latest published stable Release, pulls
its immutable image digest, replaces the disposable Box, and retains the
Workspace, Managed home, effective lifecycle settings, and saved Selections.

To qualify or install an explicitly published prerelease instead, set
`SQUAREBOX_TAG` to its complete tag before running the installer or rebuild.
Raw Git tags and draft Releases are not stable-install discovery inputs.

After rebuilding, verify that the MOTD, `/usr/local/lib/squarebox/VERSION`, the
checked-out source, and the digest in the Install identity all describe the
same Release.

## User-visible changes

- The base image includes `bubblewrap`, allowing the OpenAI Codex CLI to use the
  system `bwrap` sandbox helper.
- Elio can be selected as a TUI file manager.
- Herdr can be selected as an agent multiplexer.
- Oh My Pi can be selected as an AI coding harness and launches as `omp`.
- Fresh managed Zellij configuration includes Ctrl+B as an alternate leader, a
  prefix-mode help popup, and safe detach behavior when a client disappears.
- Dev Containers retain authentication, history, and mise toolchains in an
  isolated Managed-home volume across rebuilds, and their noninteractive
  defaults can select terminal multiplexers. Codespaces also include a pinned
  SSH server Feature so `gh codespace ssh` works with the custom image, and
  post-create reconciliation remains noninteractive even when given a PTY.
- Image-level Docker PUID/PGID remapping remains compatible with read-only
  managed files beneath `/home/dev`. For the POSIX lifecycle adapter, a native
  unprivileged Linux install must use the invoking account IDs; intentional
  NAS/Unraid remapping requires a root-run rootful runtime.
- xh, just, and mise advance with reviewed amd64 and arm64 checksums.

The new optional tools are not forced into an existing Selection. Run
`sqrbx-setup tuis`, `sqrbx-setup multiplexers`, or `sqrbx-setup ai` to add
Elio, Herdr, or Oh My Pi. Elio and Herdr are verified GitHub-release tools in
the Managed home; Oh My Pi is managed through mise there. All survive Box
replacement when selected and successfully observed.

## Existing Zellij configuration

Squarebox migrates only the exact unmodified legacy managed Zellij default.
User-edited files, symlinks, and an explicit `on_force_close` choice are
preserved rather than overwritten. Re-run `sqrbx-setup multiplexers` after
reviewing a custom configuration if you want to adopt the new defaults
manually.

## Rollback

1. Stop the v1.2 Box; do not purge the Workspace or Managed home.
2. Re-run the published v1.1.0 installer with
   `SQUAREBOX_TAG=v1.1.0`.
3. Confirm that the restored Box uses the v1.1.0 source and image identity.

Rolling back replaces the disposable Box and image-tier tools. It does not
remove Managed-home tools installed during v1.2; remove any unwanted Elio,
Herdr, or Oh My Pi state explicitly after backing it up.
